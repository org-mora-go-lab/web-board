# 1.0.x 버전 이력

{1.0.9 이력 작성 시점에 요약본 작성}

<br>

## 1.0.0

1. 게시글 목록·검색·작성·상세·수정·삭제(CRUD)를 제공하는 게시판 구현

2. 카카오·Google(Gmail) 소셜 로그인과 이메일 회원가입·로그인, HttpOnly 세션 쿠키 기반 인증 추가

3. Next.js Route Handler 기반 `/api` 백엔드와 SQLite(sql.js) 파일 데이터베이스 구성

4. `PRD.md` 요구사항별 Playwright E2E 테스트(화면·API) 63건과 카카오·Google 모의 OAuth 서버 추가

<br>

## 1.0.1

1. 실제 소셜 로그인 키 없이 기본 카카오·Google 계정으로 로그인할 수 있는 `npm run mock` 실행 환경 추가, 개발 환경과 DB·빌드 폴더 분리

2. SQLite(sql.js)를 비동기 libSQL 클라이언트로 교체하여 로컬 SQLite 파일과 외부 Turso DB 지원

3. Vercel의 로컬 DB 파일 쓰기로 발생하는 API 500 오류를 해결하도록 외부 DB 연결 구성, 회원·계정 생성 트랜잭션과 비동기 세션·게시글 처리 적용

4. Turso 연결 환경변수와 Vercel 배포 절차 문서화, Mock·로컬 E2E의 운영 DB 설정 상속 방지

5. Mock 실행 및 원격 libSQL HTTP 저장 검증을 추가하여 Playwright E2E 테스트를 65건으로 확장, `PRD.md` 요구사항과 동기화
